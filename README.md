# Employee Management System

A desktop-based Employee Management System developed using Java Swing and MySQL.

## Project Description

This application helps manage employee records through a simple graphical user interface.

## Features

- User Login
- Add Employee Details
- View Employee Details
- Update Employee Information
- Remove Employee Records
- MySQL Database Connectivity

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- Eclipse IDE

## Database Configuration

1. Install MySQL Server.
2. Open MySQL Workbench.
3. Create the required database.
4. Configure database credentials in Conn.java using environment variables DB_USER and DB_PASSWORD.
5. Create the required tables.

## How to Run

1. Clone this repository.
2. Open Eclipse IDE.
3. Import the project.
4. Add MySQL Connector/J to the project.
5. Configure the database connection.
6. Run the application starting class.
